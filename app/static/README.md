# Bundled fonts

`Geist.woff2` and `GeistMono.woff2` are the variable Latin subsets of Geist and Geist Mono
(Vercel, SIL Open Font License 1.1, https://github.com/vercel/geist-font). They are served
by Streamlit's static file serving (`enableStaticServing` in `.streamlit/config.toml`) so the
app looks the same with no internet connection.
